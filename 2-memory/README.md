# Layer 2 — Memory

The thinking layer. Where new information arrives before it's been processed or organized.

## What Lives Here

- Voice notes and transcripts
- Diary entries
- Written notes (streaming, daily)
- Email intake
- Unstructured observations

## Where It Actually Lives

Memory is unstructured by nature and lives in **Notion** (Layer 2 databases: Voice Notes, Diary, Notes, Email Hub). This repo does not store memory content.

This directory exists to keep the 4-layer model complete and to document how Memory connects to the other layers.

## How Memory Flows

```
Raw input arrives (voice, text, email)
        │
        ▼
  Layer 2: Memory (Notion)
  Unstructured, timestamped, tagged
        │
        │  Cornelius processes:
        │  extract tasks, route insights, classify
        │
        ├──→ Layer 1: Execution (tasks, projects)
        └──→ Layer 3: Reference (context vault, SOPs)
```

Memory is the intake funnel. Nothing stays here permanently — it either becomes execution (Layer 1) or reference (Layer 3), or it stays as historical record.

## Databases (in Notion)

- **Voice Notes** — Transcribed audio with metadata, "Note to Cornelius" field for explicit routing instructions
- **Diary** — Structured operational entries (PM format: key actions → decisions → open loops → insights → top 3 tomorrow)
- **Written Notes** — Streaming and daily notes
- **Email Hub** — Classified inbound email with action codes
