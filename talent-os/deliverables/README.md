# deliverables/

Finished, shippable outputs land here — optimized JDs, interview guides, screening shortlists,
phone-screen designs, workforce plans, culture reads, total-rewards docs, analytics.

Naming: `<skill>-<subject-slug>-YYYY-MM-DD.md` (e.g. `jd-optimizer-retail-sales-associate-2026-07-18.md`).
Markdown is the source of truth; render to HTML/PDF/DOCX from it when you need to hand something off.

**Confidential — git-ignored.** Generated outputs can contain candidate names, comp, and PII, so
nothing here is committed except this README. Move a deliverable elsewhere deliberately if you want
it tracked.
