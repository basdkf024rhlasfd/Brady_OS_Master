# intake/data/

Drop structured data here: roster/headcount exports, funnel/ATS metrics (applies → screens →
interviews → offers → hires, time-to-fill, source), exit/turnover data, comp/benefits data, and
survey results. CSV is ideal; pasted tables work too.

**Feeds:** `people-analytics`, `workforce-plan`, `total-rewards`, `culture-diagnostic`.
**Confidential — git-ignored (PII + comp).** Only this README ships.

The analytics are only as good as the fields you give. If a metric needs a column you don't have,
the skill will tell you exactly what to pull next — it won't fabricate it.
