# Orlando Real Estate Knowledge Base

A Claude Code plugin and web viewer with comprehensive Orlando FL real estate knowledge, agent workflows, and community-concierge guidance for the Orlando metro area.

## Quick Start

1. Go to [https://github.com/basdkf024rhlasfd/Orlando](https://github.com/basdkf024rhlasfd/Orlando)
2. Click the green **<> Code** button
3. Click **Download ZIP**
4. Go to [https://claude.ai](https://claude.ai) and create a new Project
5. Upload the ZIP file to the project knowledge
6. Start asking about Orlando real estate
