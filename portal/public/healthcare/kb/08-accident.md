# Accident Insurance — Sun Life · Policy #956845

Pays **cash directly to us** (not the doctor) when someone has a covered accident — **on top of all other coverage**. Use it for anything: deductibles, copays, lost income, childcare. No health questions, no network. Covers accidents at work, home, or away (24-hour). Child coverage to age 26.

## What it pays (examples)

| Event | Cash benefit |
|---|---|
| Hospital admission | $1,000 |
| Hospital stay (per day) | $250/day |
| ICU admission / stay | $2,000 / +$500 per day |
| Ambulance — ground / air | $300 / $1,000 |
| ER admission | $200 |
| Concussion | $50 |
| Broken leg (closed/open) | $1,000 / $2,000 |
| Torn knee cartilage / ruptured disc / ligament | $500 each |
| Wellness screening (per person, once a year) | **$50 — easy money: claim it after any annual physical, bloodwork, or cancer screening** |
| Accidental death (employee) | $25,000 (+$100,000 if on a plane/bus/train as passenger) |

## How to file

1. Download the claim form at sunlife.com/us (or call 800-247-6875).
2. You + the treating doctor provide details of the accident/treatment.
3. For the $50 wellness benefit: submit proof of a screening (physical, bloodwork, cancer screening, immunization, kids' sports physicals, etc.) — once per year per person.

This is limited accident insurance, not health insurance. Exclusions apply (e.g., injuries from intoxication, certain extreme sports). See the certificate for the full list.
