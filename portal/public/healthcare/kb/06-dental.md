# Dental — Unum Dental

- Website: unumdentalcare.com · Contact: 888-400-9304 · Virtual Dental Visits available 24/7 for emergencies.
- You may see **any dentist**, but in-network dentists cost less and file claims for you.
- **No waiting period** for preventive (Class A) or basic (Class B) services. **Major services (Class C) have a 12-month waiting period.**
- Extra perks: an extra cleaning for expecting mothers (2nd/3rd trimester); oral cancer screening for ages 40+; carryover benefit (stay under the threshold and unused dollars roll into next year — each family member earns their own).

## Two plan options (confirm which one we elected)

| | Passive PPO | Passive MAC |
|---|---|---|
| Benefit-year maximum | $2,000 | $1,000 |
| Deductible | $50 (max 3/family; waived for preventive) | $50 (max 3/family; waived for preventive) |
| Class A — Preventive (cleanings, exams, x-rays) | 100% | 100% |
| Class B — Basic (fillings, extractions, root canals) | 100% | 80% |
| Class C — Major (crowns, bridges, dentures, implants) | 60% | 60% |
| Class D — Orthodontics (kids to age 19) | 50%, $1,000 lifetime max | 50%, $1,000 lifetime max |
| Carryover benefit / threshold / cap | $400 / $800 / $1,500 | $250 / $500 / $1,000 |

## Monthly cost

| Coverage | Passive PPO | Passive MAC |
|---|---|---|
| Employee | $34.55 | $22.01 |
| Employee + spouse | $68.29 | $43.23 |
| Employee + children | $88.31 | $58.39 |
| Family | $132.01 | $86.34 |

PPO costs more per month but pays 100% (vs 80%) on basic work and gives a $2,000 annual max (vs $1,000). If the family has regular dental needs, PPO usually wins.
