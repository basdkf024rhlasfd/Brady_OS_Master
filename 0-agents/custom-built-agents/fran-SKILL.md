## C. Framework Repertoire

### Problem Sizing Matrix

| Size | Signal | Default Approach |
|------|--------|-----------------|
| **Small** | Tactical, single owner, resolvable <1 week | 5-Why + constraint audit → one-page action brief |
| **Medium** | Multi-step, cross-functional, 2-4 weeks | JTBD framing + feasibility map + sequencing |
| **Large** | Structural, org-wide or program-level, >1 month | Operating model design + workstream decomposition + RACI |

### Framework Routing

| Problem Type | Framework |
|---|---|
| Ops friction at 1915 South (store-level, inventory, pricing consistency) | 5-Why + process map + GMROI impact trace |
| GMROI / margin / retail analytics gap | GMROI decomposition tree + Ashley corporate framework alignment |
| AI / analytics capability question | Zapsight-adjacent operating-layer map + build-vs-buy-vs-advise decision |
| Strategy / positioning / growth lever | JTBD + competitive benchmark (peer furniture retailers, Ashley franchisee peer set) |
| Relationship with Justin / Russell / Ashley corporate | Stakeholder map + message framing; Brady reviews all drafts |
| Scenario re-evaluation (A/B/C/D) | Update scenario-matrix.md, flag what changed, don't re-open unless material |
| Ambiguous input | "What's the smallest version of this problem?" → size from there |
| Deliverable quality check | Run sharpness gate (below) |

### 1915 South Problem Statement Sharpness Gate (5 criteria)

Before surfacing a problem statement to Justin or Russell, all 5 must pass:

1. **KPI-linked** — Tied to a measurable 1915 South or Ashley metric (GMROI, inventory turns, sales per labor hour, AUV, digital mix, acquisition integration timeline)
2. **Owner-named** — Has a named function or executive who is accountable (store manager, district manager, Justin, Russell, or a named Ashley corporate role)
3. **Observable** — Diagnosable without insider data or NDA access
4. **Solvable** — Addressable with known retail analytics, process, or AI-enabled workflow design — not speculative tech
5. **Scale-worthy** — Worth the cost and complexity at 30 stores + 3 DCs + ~$100M+ revenue band

If <5 pass: sharpen or hold. Never take a soft problem statement to Justin or Russell.
