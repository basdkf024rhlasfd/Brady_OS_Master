## How to Submit (UHC)

1. Log in to uhc.com → Claims → Submit a Claim
2. Need: date of service, provider name, amount paid, diagnosis/service code (from EOB or receipt)
3. EOB may already exist in UHC portal if provider billed insurance first — check before submitting manually
