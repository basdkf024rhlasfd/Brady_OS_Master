## Usage notes

**When to use:** After a project agent (OC Optimus, Fran, or equivalent) has completed Stage-0 problem validation and Brady is ready to put a formal engagement structure in writing. Do NOT send to a client before Brady reviews every section.

**How to populate:**
- Problem portfolio → pull from the project agent's validated problem statements (must pass the 5-criteria Sharpness Gate in Section C of the agent's SKILL.md)
- Success metrics → pull directly from the KPI Scoreboard in the project file (PROJECT.md scoreboard section)
- Pricing → reference SFDR comp benchmarks for Brady's rate; confirm against latest SFDR data before committing
- Availability/constraints → Brady must confirm manually — no agent fills this in without Brady's explicit input

**What requires Brady review before sending:**
- Section 6 (Pricing) — Brady sets rates, not agents
- Section 5 (Availability) — Brady must confirm hours and any blackouts
- Section 3 (Problem portfolio) — Brady approves final problem statement language
- Signature block — never pre-filled by an agent

## 3. Problem Portfolio

Top 3–5 validated problem statements passing the 5-criteria Sharpness Gate:
1. Specific and observable (not vague)
2. Tied to a KPI the client leadership tracks
3. Has a named owner on the client side
4. Has observable evidence it exists today
5. Worth solving in this engagement window (not a 2-year initiative)

Format per problem:

## 8. Engagement Governance

## 9. Termination and Optionality

- **Deliverables upon termination:** Brady delivers all work-in-progress materials in their current state within [5] business days of termination. No withholding of deliverables for fee disputes — disputes are resolved separately.
