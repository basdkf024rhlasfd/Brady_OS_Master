# Skills Layer

- Each skill gets its own folder with `SKILL.md` as the entry point
- Skills are reusable SOPs without agent identity — if it has a personality, it's an agent (goes in `0-agents/`)
- Existing skills: air-traffic-control, daily-whitepaper, evening-sweep, infographic-template (deprecated), mception-design-system, morning-sweep, project-creator, v0-to-portal, weekly-sweep
