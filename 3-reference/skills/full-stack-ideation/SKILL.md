# Full-Stack Ideation System — Human + AI Collaboration

## How It Works

1. **Define the problem** — Use SCQA framing (#1) to establish Situation, Complication, Question, Answer structure
2. **Select methods** — Pick 15-20 of the 100 methods most relevant to the problem domain
3. **Run each method** — Generate 3-5 ideas per method, constrained by real-world parameters
4. **Score and filter** — Use Idea Scoring Systems (#69) and Brutal Editing (#20) to cut the bottom 80%
5. **Produce output** �� Structured deliverable with each surviving idea as a card: method that generated it, what it is, why now, effort/impact, competitive angle

## Method Selection Guide

For **cost reduction / margin defense** problems, prioritize:
- First Principles (#3), Value Chain Expansion (#5), Constraint-Based Ideation (#8), Bottleneck Analysis (#45), Margin Stack Thinking (#49), Unbundling/Rebundling (#46), Zero-Based Design (#6)

For **product innovation** problems, prioritize:
- Jobs to Be Done (#4), Blue Ocean Strategy (#9), Analogous Inspiration (#15), SCAMPER (#21), Mashup Method (#24), Cultural Trend Mining (#51), Premiumization Lens (#56), Category Design (#55)

For **competitive strategy** problems, prioritize:
- Game Theory Lens (#42), Red Team/Blue Team (#72), War Gaming (#71), Opposite Thinking (#7), Second-Order Thinking (#41), Network Effects (#43), Copy and Improve (#79)

For **go-to-market / positioning** problems, prioritize:
- Identity-Based Ideation (#52), Tribal Branding (#53), Occasion-Based Thinking (#59), Narrative-First Thinking (#35), Packaging Innovation (#58), Meme-ability Test (#54)

## Output Format

When running ideation for a client or problem, produce a structured deliverable:

### For each surviving idea:
- **Idea name**
- **Method that generated it** (number and name from the 100)
- **What it is** (2-3 sentences)
- **Why now** (what signal or constraint makes this timely)
- **Effort / complexity** (Low / Medium / High)
- **Impact estimate** (Low / Medium / High)
- **Competitive angle** (how this creates advantage)
- **First move** (what to do in the next 48 hours to test this)

### Summary artifacts:
- **Prioritization matrix** (effort vs. impact, 2x2)
- **Top 3 "do now"** ideas
- **Top 3 "explore further"** ideas
- **Ideas to kill** (with reasoning)

## Core Lesson

Ideas should not be treated as occasional sparks. They should be treated as outputs of a designed system. That system can be trained, automated, audited, and improved.
