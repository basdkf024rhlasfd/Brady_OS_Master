# Setup Checklist

The Activation Agent handles most of this conversationally. This checklist exists as a reference — you do not need to read it separately before setup.

## Prerequisites

Before you start, you need:

- A folder or repo where the system files will live
- One AI assistant that can read markdown and help write files (Claude, ChatGPT, etc.)
- A place for notes and intake (Notion, Obsidian, plain files — whatever you already use)
- A calendar you actually check

## Good Defaults

- Weekly review cadence for Projects
- Monthly review cadence for Programs
- Daily notes only if you will really use them
- One universal intake inbox before multiple databases

## Do Not Overbuild

- Do not start with every possible database
- Do not write 20 custom agents on day one
- Do not copy someone else's Programs without rewriting them
- Do not automate around a structure you have not tested manually
- Do not define more than 1 Program and 1 Project on your first day
- Do not try to get the Areas "perfect" — they're easy to rename later
