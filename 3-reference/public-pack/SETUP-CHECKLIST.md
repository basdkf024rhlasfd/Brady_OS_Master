# Setup Checklist

Use this before you try to instantiate the system.

## Minimum Tool Stack

Choose one option in each category.

### AI Workspace

- Claude Desktop or Claude Code
- ChatGPT
- another capable chat model with file awareness

### System of Record

- Notion
- another database or workspace tool you trust for structured records

### Calendar and Email

- Google Workspace
- another calendar/email stack you already live in

## Local Prerequisites

- a folder or repo where the system files will live
- a notes/intake destination
- a calendar you actually use
- one place for Programs and Projects
- one AI assistant that can read markdown and help write files

## Recommended First Decisions

- Pick 4-5 Areas, not 9
- Start with 1 real Program
- Start with 1 real Project
- Keep the agent roster tiny at first
- Add automation only after the structure makes sense manually

## Good Defaults

- Weekly review cadence for Projects
- Monthly review cadence for Programs
- Daily notes only if you will really use them
- One universal intake inbox before multiple intake databases

## Do Not Overbuild

- do not start with every possible database
- do not write 20 custom agents on day one
- do not copy someone else's Programs without rewriting them
- do not automate around a structure you have not tested manually
