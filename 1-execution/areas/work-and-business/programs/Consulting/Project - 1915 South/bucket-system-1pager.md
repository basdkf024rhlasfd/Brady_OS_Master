# Bucket System — 1-Pager

**Live within $150K base + run buckets clean → save aggressively for Big Things.**

---

## 3-Account Map

| **OPERATING** (checking) | **BUCKETS** (HYSA, named subs) | **RESERVES** (savings + brokerage) |
|---|---|---|
| Base comp lands here | Quarterly bonus refills these | Rainy Day $25K (untouchable) |
| Fixed bills auto-pay | Spend down to ~$0 by quarter end | 529s — auto $1,260/mo |
| Day-to-day swipes | Score → refill on bonus day | Roth + brokerage — auto |
| Ends pay period flat | Buffer absorbs overshoots | **BIG THINGS** ← flex flows here |

## The 10-Min Pre-Bonus Ritual

1. **Did any bucket run dry too early?** → bump it
2. **Did any bucket finish with leftovers?** → trim it
3. **Does anyone need more next quarter?** → adjust

Then deposit fires → Buffer tops up → everything else → Big Things.

---

## Scoring

🟢 **Green** — 0–25% leftover, Buffer untouched
🟡 **Yellow** — >25% leftover OR Buffer tapped <$2K
🔴 **Red** — Buffer tapped >$2K OR multiple overshoots

| Grade | Meaning | Action |
|---|---|---|
| **A** | all 🟢 | raise Big Things rate |
| **B** | 1–2 🟡 | minor tuning, hold |
| **C** | any 🔴 | fix the bucket |
| **D** | Buffer tapped >$5K | scope creep — talk it out |
