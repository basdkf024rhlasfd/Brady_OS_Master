# Mark Schmulen AI OS — Delivery Plan

## Phase 1: Context Extraction (Days 1-3)

### Interview Mark (structured extraction)
- Business overview: Mark's ventures, Contour's mission/product/market, team, competitive position
- Daily workflow: What tools, in what order, for what tasks
- Communication preferences: Tone, sign-offs, formality level, formatting
- Marketing context: Brand voice, GTM strategy, manifesto, website, target audience
- Financial context: QuickBooks structure, common investor questions, reporting cadence
- Process inventory: Repeatable tasks that should become skills

### Deliverable
- Complete AGENTS.md (system prompt with full business context)
- Initial MEMORY.md (seeded with extracted preferences)
- Process list prioritized for skill conversion

## Phase 2: Agent Build (Days 4-7)

### Executive Assistant
- AGENTS.md section: Role, daily routine, communication rules
- MCP connections: Gmail, Google Calendar, Slack, Notion
- Starter skills: `/email-draft`, `/meeting-prep`, `/follow-up`
- Memory seeds: Email sign-off preference, scheduling rules, response tone

### CMO Agent
- AGENTS.md section: Brand context, GTM strategy, content rules, voice guide
- MCP connections: Same as exec assistant + any marketing tools
- Starter skills: `/content-draft`, `/landing-page`, `/investor-update`
- Context folder: Manifesto, GTM brief, competitor overview, brand guidelines
- Memory seeds: Content formatting preferences, channel strategy, design style

### Quality Gates
- Phil review: "Does each agent save Mark real time on a real task?"
- Bo check: "Are we building three agents or accidentally building a platform?"

## Phase 3: Delivery & Training (Days 8-10)

### Handoff
- Deploy agents to Mark's preferred harness (likely Cowork or Claude Code)
- Walk through: how to use, how to add skills, how memory works, how to prune
- Live demo: run a real task through each agent with Mark watching
- Troubleshooting: common issues, how to reset, when to update AGENTS.md vs MEMORY.md

### Success validation
- Mark completes one real email workflow through exec assistant
- Mark generates one real marketing artifact through CMO agent
- Mark corrects one preference and sees it persist in next session

## Phase 4: CFO Agent (Optional, Days 11-14)

### CFO Agent
- AGENTS.md section: Financial context, reporting structure, investor FAQ
- MCP connections: QuickBooks (if available), Google Sheets/Docs
- Starter skills: `/journal-entry`, `/investor-answer`, `/financial-summary`
- Context folder: Chart of accounts, investor question history, reporting templates
