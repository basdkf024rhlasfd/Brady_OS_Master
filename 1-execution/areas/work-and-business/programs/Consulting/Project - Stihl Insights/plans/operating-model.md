# Operating Model: What Rob Receives

## The Core Promise

Rob gets a fractional insights team that produces more, faster, and with better analytical depth than a dedicated internal hire — maintained at a fraction of the cost because the system compounds over time.

## Weekly Deliverable

Every week, the surface updates with:

### 1. Fresh Home Briefing
- Updated "what matters now" — the single most important competitive or market development
- Updated recommendation — what Rob's team should do about it
- Refreshed favorited prompts tied to the current situation
- "New since last update" bullets (3-5 max)

### 2. Competitor Updates
- Any material changes to tracked competitors (launches, pricing, financial results, strategic moves)
- Updated competitor profiles where relevant
- New linked data supporting the changes

### 3. Digital Analytics Refresh
- Any notable changes in site performance, search, or marketplace positioning
- New audit findings if applicable
- Updated benchmarks

### 4. New or Updated Artifacts
- At least 1 new or refreshed artifact per week (battlecard, memo, talking points, etc.)
- Tied to whatever is most relevant that week
- Each comes with an updated prompt

### 5. Data Library Growth
- New facts, metrics, and source notes added
- Existing data updated where stale
- This is the compounding layer — every week the substrate gets richer

## What Makes Maintenance Cheap Over Time

The system is designed so that weekly updates get faster, not harder:

1. **Data accumulates.** Every fact, metric, and source note stays in the library. Updates build on what's already there instead of starting from scratch.
2. **Prompts are reusable.** The prompt templates work with updated data — Rob (or Brady) can regenerate artifacts by pasting the prompt with fresh context.
3. **Competitor profiles are persistent.** You're updating a living profile, not writing a new brief every time.
4. **Artifacts are templates.** Once a battlecard format is proven, updating it for new data is fast.
5. **Requests create the roadmap.** Rob's own requests tell you exactly what to prioritize each week — no guessing.

## Weekly Maintenance Workflow

```
1. Check for new requests from Rob             (5 min)
2. Scan competitor news and market moves        (15 min)
3. Update data library with new facts           (10 min)
4. Update Home briefing                         (10 min)
5. Update affected competitor profiles          (5 min)
6. Produce or refresh 1 artifact                (10 min)
7. Quick review pass on the full surface        (5 min)
                                        Total: ~60 min
```

This is the target state. Early weeks will take longer as the data library builds out and the content patterns stabilize.

## What Rob Should Experience

- Opens the surface and immediately knows what changed and why it matters
- Copies a prompt into his AI tool and gets a useful output on the first try
- Submits a request and gets a response within the week
- Sees the surface getting smarter and more useful over time
- Never has to learn the system — it's obvious on arrival
- Trusts it enough to reference in leadership conversations

## Escalation Path

If Rob needs something outside the normal weekly update:
1. Submit a request through the surface
2. Brady triages and responds (same day for urgent, within the week for standard)
3. Artifact or analysis delivered and added to the surface

The surface is the single source of truth. Nothing lives only in email or Slack.
