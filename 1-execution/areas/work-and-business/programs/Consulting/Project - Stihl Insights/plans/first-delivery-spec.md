# First Delivery Spec: What Ships to Rob

## Definition of Done

The initial delivery is complete when Rob can open the STIHL surface and:
1. Understand the most important competitive development in under 60 seconds
2. Copy a prompt into ChatGPT or Claude and get a useful result immediately
3. Open an artifact and see a finished, presentation-ready example
4. Browse competitor profiles with real substance behind them
5. See a data library that proves accumulated intelligence, not a demo

## What Must Be Populated

### Home (the front door)
- [ ] 1 "what matters now" insight — specific, dated, actionable
- [ ] 1 recommendation — what Rob should do about it
- [ ] 2-3 favorited prompts with copy-to-clipboard
- [ ] 1 featured artifact
- [ ] 3-5 "new since last update" bullets
- [ ] 1 recently updated data block

### Competitors (6 profiles)
- [ ] Husqvarna — full profile (position, latest moves, why it matters, linked data)
- [ ] Deere & Co — full profile
- [ ] Toro — full profile
- [ ] Honda Power Equipment — full profile
- [ ] Echo / Yamabiko — full profile
- [ ] Milwaukee Tool (TTI) — full profile

Each profile must include:
- Current competitive position relative to STIHL
- At least 2 recent developments (dated, sourced)
- "Why this matters" framing
- Linked artifacts and data items

### Digital Analytics
- [ ] stihlusa.com performance observations (real findings)
- [ ] At least 2 competitor site comparisons
- [ ] SEO / search observations
- [ ] Marketplace presence observations (Amazon, Home Depot, Lowe's)
- [ ] At least 3 specific, actionable feature gaps

### Artifacts (6 minimum)
- [ ] Executive one-pager (finished example)
- [ ] Tariff impact memo (finished example)
- [ ] Husqvarna battlecard (finished example)
- [ ] Digital benchmark snapshot (finished example)
- [ ] Leadership briefing template (with prompt)
- [ ] Dealer talking points template (with prompt)

Each artifact must have:
- The finished deliverable (not an outline)
- An attached prompt that can regenerate or customize it
- Copy-to-clipboard on the prompt
- Clear label: who it's for, when to use it

### Prompts (8-12 templates)
Living inside Artifacts but also featured on Home. Categories:
- [ ] Daily competitive brief
- [ ] Competitor battlecard generator
- [ ] Tariff impact analysis
- [ ] Digital audit prompt
- [ ] Leadership update memo
- [ ] Dealer talking points
- [ ] Market share analysis
- [ ] Product launch assessment

Each prompt follows the structure:
- Role, task, required output format
- Available context (what to paste in)
- Tone and audience
- Citation expectation

### Data Library (minimum 30 items)
- [ ] Financial metrics: revenue, margins, stock data for STIHL peers (8-10 items)
- [ ] Tariff and trade: current tariff rates, policy changes, impact estimates (4-6 items)
- [ ] Product launches: recent launches across competitors (4-6 items)
- [ ] Market share: category share estimates, channel mix (3-5 items)
- [ ] Digital benchmarks: traffic, search rankings, marketplace metrics (4-6 items)
- [ ] Source documents: key reports, earnings transcripts, articles (3-5 items)

Each data item must have: title, type, source, date, tags, status

### Requests
- [ ] Intake form working (text input + suggested quick actions)
- [ ] At least 4 suggested quick actions pre-loaded
- [ ] Optional deadline field
- [ ] Clear, concierge tone — not a ticket system

## Quality Gate (Phil Review)

Before delivery, Phil reviews against these questions:
1. Does every section pass the content test? (specific, dated, says why STIHL cares, implies action)
2. Is there any builder-facing language visible to Rob?
3. Can someone unfamiliar with the system understand what they're looking at?
4. Are the prompts actually useful — would they produce a good output if pasted into ChatGPT right now?
5. Do the artifacts look presentation-ready, not like drafts?
6. Is the data library substantive enough to feel like accumulated intelligence?

## What Does NOT Ship in V1

- Built-in chat or AI integration
- Backend scheduling or automation
- Real-time data feeds
- User accounts beyond Rob
- Notification system
- Mobile-specific layout
- File upload capability
- API integrations

These are all future possibilities. V1 is a content surface that proves the model works.
